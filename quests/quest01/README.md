## Quest01 — Summary

`https://img.shields.io/badge/language-Go-blue`  
`https://img.shields.io/badge/focus-Setup%20%26%20Foundations-green`

### Overview
Quest01 is the **onboarding quest** of the Piscine Go program.  
It introduces students to:
- The Piscine methodology
- Git basics
- Collaboration and communication
- First steps with Go
- Camp exercises to practice discipline and teamwork

This quest is less about coding complexity and more about **building habits, environment setup, and mindset** for the Piscine.

---

### Exercises Progression

| Exercise              | Focus Area | Skills Practiced |
|-----------------------|------------|------------------|
| **introduction**      | Orientation | Understanding Piscine structure |
| **make-it-better**    | Improvement | Iteration, feedback loops |
| **who-are-you**       | Self‑presentation | Communication, identity |
| **to-git-or-not-to-git** | Git basics | Version control, commits |
| **cl-camp1–cl-camp8** | Camp tasks | Discipline, collaboration, consistency |
| **now-get-to-work**   | Transition | Moving from setup to coding |
| **explain**           | Reflection | Explaining concepts clearly |
| **teacher**           | Mentorship | Teaching peers, reinforcing knowledge |

---

### Standard Library Equivalents
Since Quest01 is mostly about **setup and communication**, the Go standard library equivalents are minimal.  
However, the exercises prepare you for:
- Using `fmt` for printing
- Using `os` for environment interaction
- Using `git` for version control (external tool, not Go)

---

### Skills Progression
Quest01 builds progressively:
1. **Orientation & mindset** → `introduction`, `make-it-better`, `who-are-you`
2. **Tooling basics** → `to-git-or-not-to-git`
3. **Discipline & collaboration** → `cl-camp1` through `cl-camp8`
4. **Transition to coding** → `now-get-to-work`
5. **Communication & teaching** → `explain`, `teacher`

By the end, you’ve practiced:
- Piscine methodology
- Git basics
- Communication and teamwork
- Discipline and consistency
- First steps toward Go coding

---

### Key Takeaway
Quest01 sets the stage for the Piscine: it’s about **mindset, discipline, and collaboration**.  
It demonstrates how the Piscine emphasizes not just coding, but also **habits, communication, and teamwork** — the foundation for succeeding in later quests.
