## Quest11 — Summary

### Overview
Quest11 focuses on **linked list operations**. You’ll implement a series of functions that manipulate singly linked lists, covering insertion, deletion, traversal, searching, merging, and sorting.  

This quest is about mastering:
- **Pointers and struct types** in Go
- **Dynamic memory management** (creating and linking nodes)
- **Algorithmic thinking** with list operations

---

### Exercises Progression

| Exercise              | Focus Area | Skills Practiced |
|-----------------------|------------|------------------|
| **listpushback**      | Insertion  | Add element at end |
| **listpushfront**     | Insertion  | Add element at front |
| **listsize**          | Traversal  | Count elements |
| **listlast**          | Traversal  | Find last element |
| **listclear**         | Deletion   | Free all nodes |
| **listat**            | Access     | Retrieve element at index |
| **listreverse**       | Reversal   | Reverse list order |
| **listforeach**       | Iteration  | Apply function to each element |
| **listforeachif**     | Conditional iteration | Apply function if condition met |
| **listfind**          | Search     | Find element by value |
| **listremoveif**      | Conditional deletion | Remove nodes matching condition |
| **listmerge**         | Merge      | Concatenate two lists |
| **listsort**          | Sorting    | Sort list elements |
| **sortlistinsert**    | Sorted insertion | Insert while maintaining order |
| **sortedlistmerge**   | Merge sorted lists | Efficiently combine ordered lists |

---

### Skills Progression
Quest11 builds progressively:
1. **Basic insertions** → `listpushback`, `listpushfront`
2. **Traversal and access** → `listsize`, `listlast`, `listat`
3. **Mutations** → `listclear`, `listreverse`, `listremoveif`
4. **Functional iteration** → `listforeach`, `listforeachif`
5. **Searching and merging** → `listfind`, `listmerge`
6. **Sorting and advanced merges** → `listsort`, `sortlistinsert`, `sortedlistmerge`

By the end, you’ll have implemented a **mini linked list library** in Go.

---

### Key Takeaway
Quest11 is about **data structures**. You move from arrays and slices (fixed, contiguous memory) to linked lists (dynamic, pointer‑based). This teaches:
- How to manage memory dynamically
- How to traverse and manipulate non‑contiguous data
- How to implement algorithms on linked structures
