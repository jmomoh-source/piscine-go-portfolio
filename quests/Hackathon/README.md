# Quest10 — Hackathon

![Go](https://img.shields.io/badge/language-Go-blue)
![Status](https://img.shields.io/badge/status-completed-success)
![License](https://img.shields.io/badge/license-MIT-green)

## Overview
Quest10 was a **Hackathon challenge** in the Piscine Go program.  
It consisted of a set of small but tricky exercises designed to test problem‑solving speed, algorithmic thinking, and mastery of Go basics under time pressure.

The hackathon included tasks such as:
- String manipulation
- Bitwise operations
- Mathematical sequences
- Array/slice transformations
- Simulation problems

## Exercises
Here’s the full list of hackathon tasks:

| Exercise                | Description                                                                 |
|--------------------------|-----------------------------------------------------------------------------|
| `rot14`                 | Implement a Caesar cipher with a rotation of 14.                           |
| `descendcomb`           | Generate descending combinations.                                          |
| `unmatch`               | Find the element without a pair.                                           |
| `fooddeliverytime`      | Calculate delivery time based on distance and speed.                       |
| `collatzcountdown`      | Implement the Collatz sequence countdown.                                  |
| `abort`                 | Handle program termination gracefully.                                     |
| `shoppingsummarycounter`| Count items in a shopping summary.                                         |
| `compact`               | Remove duplicates or compress data.                                        |
| `dealapackofcards`      | Simulate dealing cards from a deck.                                        |
| `jumpover`              | Implement jump‑over logic in arrays.                                       |
| `stringtointslice`      | Convert a string of numbers into a slice of ints.                          |
| `join`                  | Concatenate strings with a separator.                                      |
| `enigma`                | Encode/decode using a custom cipher.                                       |
| `descendappendrange`    | Append ranges in descending order.                                         |
| `shoppinglistsort`      | Sort shopping list items.                                                  |
| `comcheck`              | Compare values for equality.                                               |
| `reversemenuindex`      | Reverse menu indices.                                                      |
| `podiumposition`        | Determine podium positions from scores.                                    |
| `activebits`            | Count active bits in an integer.                                           |
| `pilot`                 | Simulate pilot navigation logic.                                           |
| `fixthemain`            | Debug and fix a broken `main` function.                                    |
| `max`                   | Find the maximum value in a slice.                                         |
| `rockandroll`           | Implement a playful string/logic transformation.                           |
| `loafofbread`           | Simulate slicing and distributing bread.                                   |

## Skills Practiced
- Fast problem solving under time constraints
- Go fundamentals (slices, strings, maps, structs)
- Algorithmic thinking
- Debugging and refactoring
- Simulation and modeling

## Notes
- The hackathon was timed and designed to push participants to **write clean, working code quickly**.
- Each exercise reinforced core Go concepts while demanding creativity.
- Completing this hackathon demonstrates readiness for real‑world coding challenges.
