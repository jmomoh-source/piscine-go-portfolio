The **Quests** are the main learning path of the Piscine-Go bootcamp, progressively building Go proficiency from foundations through advanced data structures and concurrency.

Each quest contains **multiple exercises** that reinforce specific learning objectives. Exercises are designed to be solved in order within each quest.

### Quest10 — Hackathon Challenges
**Difficulty:** Intermediate–Advanced | **Exercises:** 13 | **Estimated Completion Time:** 6–8 hours  

Rapid-fire problem-solving challenges designed to test adaptability and mastery of Go fundamentals under time pressure.

**Key Topics:**
- String concatenation and parsing
- Pointer manipulation
- Slice building and reversal
- Custom sorting
- Command-line tools
- Structs and debugging
- Bitwise operations
- Conditional logic

**Exercises:**
- `join`, `enigma`, `descendappendrange`, `shoppinglistsort`  
- `comcheck`, `reversemenuindex`, `podiumposition`  
- `activebits`, `pilot`, `fixthemain`  
- `max`, `rockandroll`, `loafofbread`
